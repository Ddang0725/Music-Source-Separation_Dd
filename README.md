# 음원분리댕

음악 파일을 **보컬 / 드럼 / 베이스 / 기타 / 나머지 반주(피아노 포함)**로 분리하는 Windows 데스크톱 프로그램입니다.

## 실행

1. `음원분리댕.exe` 또는 `Start.cmd`를 실행합니다.
2. 처음 한 번 **AI 엔진 설치 / 복구**를 누릅니다. 자동 모드는 NVIDIA GPU가 감지되면 GPU용 라이브러리를 설치합니다.
3. 음악 파일과 결과 저장 폴더를 고릅니다.
4. **음원 분리 시작**을 누릅니다.
5. 완료 후 **전체 듣기**와 파트별 볼륨·음소거로 조절하거나 **결과 폴더 열기**로 WAV 파일을 확인합니다.

설치와 최초 모델 다운로드에는 인터넷 연결과 수 GB의 여유 공간이 필요합니다. 설치가 끝나고 모델이 준비되면 분리는 로컬 PC에서 수행됩니다. 오디오 파일을 외부 서버에 업로드하지 않습니다.

## 현재 확인 상태

- 실행 파일 빌드 및 Python 구문 확인 완료.
- 저장 결과 검증, 원본 보존, 이름 중복 방지, GPU 메모리 부족 시 CPU 재시도, 실패 시 불완전한 결과 숨김 등을 모의 엔진으로 검증했습니다.
- 실제 GUI 초기화와 별도 프로세스 취소를 확인했습니다.
- **개발 도구 실행 환경에서 패키지 다운로드에 실패하여 실제 AI 모델로 곡을 분리하는 검증은 아직 완료하지 못했습니다.** 사용자 환경에서 실행한 프로그램의 설치 버튼으로 엔진을 설치해야 합니다.

## 시스템 요구 사항

- Windows 10/11, Python **3.10 또는 3.11 64비트**. tkinter가 포함된 일반 Python 설치본을 사용하세요.
- 실행 런처는 Windows .NET Framework 4.x를 사용합니다.
- GPU 가속은 NVIDIA CUDA 지원 GPU와 호환되는 드라이버가 필요합니다. 현재 PC의 GTX 1660 SUPER 6GB를 기준으로 CUDA 11.8용 라이브러리를 선택했습니다.
- CPU 모드도 사용할 수 있으나 곡 길이와 PC 성능에 따라 시간이 오래 걸릴 수 있습니다.
- Python이 여러 개라면 환경 변수 `SEPARATOR_PYTHON`에 사용할 `pythonw.exe` 경로를 지정할 수 있습니다.

**이 프로그램은 EXE 하나만으로 분리되지 않습니다.** 같은 폴더의 `app.py`, `engine.py`, `player.py`, `requirements.txt`를 유지해야 하며, AI 엔진도 설치해야 합니다. 다른 PC로 옮길 때는 프로그램 파일을 함께 옮긴 후 해당 PC에서 엔진을 설치하세요. `.venv`를 다른 위치나 PC로 복사해서 사용하지 마세요.

## 처리 장치와 저장 방식

- **자동 (GPU 우선)**: GPU를 사용할 수 있으면 사용하고, GPU 메모리 부족 오류가 나면 CPU로 재시도합니다.
- **GPU (NVIDIA)**: GPU 사용 불가 시 오류를 표시합니다. GPU로 분리하려면 GPU용 엔진이 필요합니다.
- **CPU**: GPU 없이 분리합니다. CPU용으로 설치한 뒤 GPU로 바꾸려면 장치를 GPU로 설정하고 설치 / 복구를 다시 실행하세요.
- 기본 결과 위치는 프로그램 안의 `결과` 폴더이며 변경할 수 있습니다.
- 결과는 `곡이름_날짜_시간` 폴더에 `vocals.wav`, `drums.wav`, `bass.wav`, `guitar.wav`, `other.wav`, `분리정보.json`으로 보관합니다. 이름이 겹치면 번호를 붙입니다.
- 다섯 파트가 모두 생성된 경우에만 완료된 결과 폴더를 공개합니다. 원곡은 덮어쓰지 않습니다.
- 실행 중 화면에는 처리 단계, 경과 시간, 실제 작업 기록을 표시합니다. 진행 막대는 작업 중임을 나타내며 정확한 완료율은 아닙니다.
- **취소**는 해당 작업의 하위 프로세스를 함께 종료하고 이번 작업의 임시 폴더를 정리합니다. 이미 완료한 결과는 삭제하지 않습니다.
- Windows 또는 PC가 강제 종료되면 결과 폴더 안에 `.separating-...` 임시 폴더가 남을 수 있습니다.

AI 분리는 완벽하지 않습니다. 파트 사이에 소리가 섞이거나 잔향과 음질 변화가 생길 수 있습니다. `other`는 피아노와 그 밖의 악기를 합친 파일입니다. 보컬·드럼·베이스·기타는 별도 파일입니다.

## 파일과 개발

- `음원분리댕.exe`: 창을 여는 런처
- `app.py`: GUI, 백그라운드 작업, 취소 및 결과 재생
- `engine.py`: AI 설치, 6파트 분리와 피아노/나머지 악기 병합
- `player.py`: 5파트 동기 재생, 시간 이동, 실시간 볼륨 믹싱
- `requirements.txt`: AI 라이브러리 버전
- `Launcher.cs`, `Build.ps1`: 런처 소스 및 빌드
- `test_engine.py`, `test_gui.py`, `test_player.py`: 모델 설치 없이 실행 가능한 처리 흐름 및 GUI 테스트
- `프로젝트기록.md`: 매 작업의 변경 사항 및 검증 결과
- `.venv`: 프로젝트 전용 Python/AI 환경 (설치 시 생성)
- `models`: 모델 캐시 (최초 준비 시 생성)

빌드: `powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1`

테스트: `python -X utf8 -m unittest -v test_engine test_gui test_player`

CLI 설치: `python -X utf8 engine.py install --accelerator auto`

CLI 분리: `.venv\Scripts\python.exe -X utf8 engine.py separate --input "음악.mp3" --output "결과" --device auto`

## 시간 바와 파트별 믹서

- **재생 / 일시정지**: 현재 위치에서 이어서 듣습니다. **정지**는 처음으로 돌아갑니다.
- **시간 바**: 원하는 위치를 클릭하거나 손잡이를 드래그한 후 놓으면 해당 위치로 이동합니다. 현재 시간/전체 길이를 표시합니다.
- **전체 듣기**: 모든 파트의 음소거를 해제하고 현재 위치부터 함께 재생합니다. 각 슬라이더에 정한 볼륨은 유지합니다.
- **파트별 볼륨**: 각 파트를 0~100%로 조절합니다. **음소거**는 해당 파트만 끄고, **단독 듣기**는 나머지 파트를 음소거합니다.
- **전체 볼륨**: 믹스 전체의 크기를 조절합니다. 초기값은 80%입니다.
- **기존 결과 열기**: 파트별 WAV 파일이 있는 결과 폴더를 다시 열 수 있습니다. 예전 4파트 결과도 재생할 수 있지만 기타는 별도 조절되지 않고 기존 반주에 포함됩니다.
- 다섯 파트를 하나의 PCM 스트림으로 섞어서 같은 위치로 재생합니다. 슬라이더 변화는 짧은 출력 버퍼 이후 반영됩니다. 설정은 듣기에만 적용되며 저장된 WAV 파일을 바꾸지 않습니다.
- 같은 길이·샘플 속도·채널 수의 16비트 PCM WAV를 지원합니다. 이 프로그램의 기본 분리 출력 형식과 같습니다.

## 기타 분리

`htdemucs_6s`로 여섯 파트를 분리한 후 피아노와 나머지 악기를 합쳐 최종 다섯 파트를 저장합니다. `piano.wav`는 별도로 보관하지 않습니다. 합칠 때 PCM 범위를 넘는 피크는 제한됩니다.

6파트 모델은 실험 모델이므로 악기 소리가 섞일 수 있습니다. 최초 사용 시 6파트 모델이 추가로 다운로드됩니다. 모델이 이미 저장되어 있다면 다시 받지 않습니다. 실제 곡에 대한 6파트 추론/품질 검증은 아직 완료하지 못했습니다.

## 프로그램 내 재생 끊김 개선

재생 시작과 시간 이동 후 출력 버퍼를 미리 채우고, 재생 중에는 빈 버퍼를 한 번에 보충하도록 개선했습니다. 약 0.2초의 출력 여유를 두므로 볼륨 변화는 그 정도 늦게 들릴 수 있습니다. 변경 후 프로그램을 완전히 종료했다가 다시 실행해주세요. 기존 결과 WAV를 그대로 사용할 수 있으며 재분리는 필요하지 않습니다.
